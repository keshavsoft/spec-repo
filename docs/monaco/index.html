definitions/

Tier 4 • UI Specs

Component Contracts & Blueprints

The Story of definitions: UI components typically mix complex rendering logic with behavioral configuration. The definitions/ layer decouples this cleanly.

It provides blueprints for 10 UI components (table, form, select, card, etc.), wiring together baseFromSpec, declarative instructions, and runtime options like search toolbars and row serial numbers.

definitions.json baseFromSpec options.search options.serial
Open definitions/index.html → Live Studio

instructions/

Tier 3 • AST Rules

Compiler Assembly Pipeline

The Story of instructions: In traditional compilers, DOM transformations require rigid imperative loops. When HTML structures change, compilers break. The instructions/ tier solves this.

It declares transformation steps like buildColgroup, buildHeader, and buildBody using declarative JSONPath rules ($..*[?@.attributes['data-role']]) and collection mapping without a single loop in compiler source code.

instructions.json buildHeader destinationPath fromCollection
Open instructions/index.html → Live Studio

spec/

Tier 2 • Blueprints

DOM Tag Specifications

The Story of spec: Instead of embedding HTML strings or JSX templates directly in JavaScript code, spec/ houses pure, serializable JSON blueprints for DOM elements.

It specifies raw HTML tags (<table>, <th>, <td>, <select>), default CSS utility classes, and dynamic interpolation tokens (${columnName}) ready for any runtime engine.

spec.json tableHeaderOnly tagSpecifications ${columnName}
Open spec/index.html → Live Studio

tags/

Tier 1 • Foundations

Tag Dictionary & Schema Validation

The Story of tags: At the very base of the declarative hierarchy sits tags/, serving as the ground-truth dictionary and rulebook for the entire design system.

It catalogs all permitted HTML primitives, their attributes, and JSON schema constraints. Compilers rely on this dictionary to validate input schemas, guarantee backward compatibility, and prevent runtime DOM defects.

tags.json tagsSchema tokenDefinitions allowedAttributes
