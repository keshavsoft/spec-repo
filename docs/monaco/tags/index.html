The Story of tags.json

The foundational tag dictionary, schema taxonomy, and token validation blueprints that enforce type safety across all declarative compilers.

Launch V1 Tags Studio →

The Ground Truth Dictionary

As a declarative system scales to dozens of components and assembly instructions, inconsistencies can arise: a developer might write class instead of attributes.class, or reference undefined string tokens.

tags.json is the authoritative dictionary that lists every allowed tag primitive, its mandatory attributes, and its semantic schema definition.

Schema Validation & Token Taxonomy

Compilers validate input tags against tags.json during build time:

  • Token Safety: Ensures all interpolation tokens (e.g. ${columnName}) are recognized and bound to data columns.
  • Attribute Normalization: Validates attributes, boolean flags, and accessibility roles (ARIA).
  • Engine Independence: Ensures that regardless of compiler version (v10 through v19), the tag taxonomy remains strictly backwards-compatible.
// Anatomy of tags taxonomy in tags.json:
{
  "tagTypes": {
    "table": { "category": "container", "children": ["thead", "tbody", "tfoot"] },
    "th": { "category": "leaf", "tokens": ["${columnName}"] },
    "td": { "category": "leaf", "tokens": ["${value}", "${serialNumber}"] }
  }
}

Guaranteed Schema Consistency

By maintaining tags.json as a separate, inspectable studio, developers can audit tag standards and verify schema integrity before publishing new releases of spec-repo.
