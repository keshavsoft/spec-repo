Quick Start

1. Install

npm install spec-repo

2. Import in ES Module

import spec, { tags, definitions, instructions } from "spec-repo";

// Access any declarative tag blueprint
console.log(spec.buildHeader);
/*
{
  "tagName": "th",
  "textContent": "${columnName}",
  "attributes": {
    "class": "py-3 px-3 fw-semibold text-uppercase small text-body-secondary border-bottom"
  }
}
*/

Core Specifications at a Glance

Spec Key Target Tag Interpolation Token Description
buildColGroup <col> ${width} Defines column width inside <colgroup>
buildHeader <th> ${columnName} Styled uppercase column header cell
buildBodyTr <tr> — Table body row with align-middle styling
buildBodyCell <td> ${rowValue} Table body data cell
buildFooter <td> ${columnName} Footer cell with datalist-bound input
buildSelect <select> — Native select dropdown container
buildOption <option> ${rowValue} Option item for select or datalist
buildDataList <datalist> ${columnName} Native autocompletion provider container
headerSerialCell <th> — Row sequence indicator header (#)
optionsButtonCell <td> — Cell housing action button (ks-btn-show)
