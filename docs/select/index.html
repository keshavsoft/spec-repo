How to Build Select Dropdowns

Generate clean, accessible HTML <select> elements and option collections using declarative blueprints.

1. The Select Specifications

Building dropdowns in spec-repo relies on two foundational tag specifications:

1. The Select Container (buildSelect)
Defines the root <select> element with Bootstrap form-control classes and aria attributes.
2. The Option Item (buildOption)
Defines <option value="${rowValue}">${rowValue}</option> with value binding.

Raw Blueprints

// 1. spec.buildSelect
{
  "tagName": "select",
  "attributes": {
    "class": "form-select",
    "aria-label": "Select Option"
  },
  "children": []
}

// 2. spec.buildOption
{
  "tagName": "option",
  "textContent": "${rowValue}",
  "attributes": {
    "value": "${rowValue}"
  }
}

2. Assembly Instructions for Select

From src/v17/instructions.json and definitions.json, there are three modes to build selects:

Instruction Type Purpose
buildSelectWithOptions columnOnRow Constructs the outer <select> container and populates all <option> children from the data source in one pass.
buildSelectOptions single Populates options into an existing pre-rendered <select> base AST.
buildOptionsArray single Generates a standalone array of option tags without an enclosing <select> (useful for dynamic option refreshes).

3. Code Example: Compiling a Select Dropdown

import { spec, definitions } from "spec-repo";

function createSelectDropdown({ inItems, inSelectedValue }) {
  // 1. Clone the select template
  const selectAst = JSON.parse(JSON.stringify(spec.buildSelect));

  // 2. Iterate through items and hydrate buildOption tags
  inItems.forEach(item => {
    const value = typeof item === "string" ? item : item.value;
    const label = typeof item === "string" ? item : item.label;

    const optionAst = {
      tagName: "option",
      textContent: label,
      attributes: {
        value: value
      }
    };

    if (value === inSelectedValue) {
      optionAst.attributes.selected = "selected";
    }

    selectAst.children.push(optionAst);
  });

  return selectAst;
}

// Sample Usage:
const dropdown = createSelectDropdown({
  inItems: ["Pending", "In Review", "Approved", "Rejected"],
  inSelectedValue: "Approved"
});

console.log(dropdown);

4. Produced Virtual AST & Resulting HTML

The compiler generates this standard AST:

{
  "tagName": "select",
  "attributes": {
    "class": "form-select",
    "aria-label": "Select Option"
  },
  "children": [
    { "tagName": "option", "textContent": "Pending", "attributes": { "value": "Pending" } },
    { "tagName": "option", "textContent": "In Review", "attributes": { "value": "In Review" } },
    { "tagName": "option", "textContent": "Approved", "attributes": { "value": "Approved", "selected": "selected" } },
    { "tagName": "option", "textContent": "Rejected", "attributes": { "value": "Rejected" } }
  ]
}

Which renders into native browser DOM:

<select class="form-select" aria-label="Select Option">
  <option value="Pending">Pending</option>
  <option value="In Review">In Review</option>
  <option value="Approved" selected="selected">Approved</option>
  <option value="Rejected">Rejected</option>
</select>
