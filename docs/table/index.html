How to Build Tables

Construct rich, responsive tables using declarative JSON templates, column mappings, 2D matrix row generators, and pluggable decorators.

1. The Table Blueprint Architecture

In spec-repo, a table is not a monolithic block of HTML. It is assembled from distinct modular parts:

1. Colgroup (buildColGroup)
Defines column widths using <col style="width: ${width};"> for stable, glitch-free browser layout calculations.
2. Header (buildHeader)
Generates uppercase column headers <th>${columnName}</th> inside the <thead>.
3. Body Rows (buildBody)
A rowOnColumn matrix execution combining row wrapper buildBodyTr with data cells buildBodyCell.
4. Footer (buildFooter)
Generates filter/entry cells containing datalist-bound inputs inside <tfoot>.

2. Step-by-Step Table Assembly

Step A: Prepare Your Input Data

The compiler requires two data structures: column definitions and row data records:

const tableData = {
  columns: [
    { columnName: "ItemName", width: "200px" },
    { columnName: "Category", width: "150px" },
    { columnName: "Price", width: "100px" }
  ],
  data: [
    { ItemName: "Mechanical Keyboard", Category: "Electronics", Price: "$120" },
    { ItemName: "Standing Desk", Category: "Furniture", Price: "$450" }
  ]
};

Step B: Pick a Table Recipe from definitions.json

spec-repo provides preset recipes for every table scenario:

import { definitions } from "spec-repo";

// Inspect the "simple" table definition:
console.log(definitions.table.simple);
/*
{
  "baseFromSpec": "tableSimple",
  "instructions": [
    "buildColgroup",
    "buildHeader",
    "buildBody"
  ],
  "options": {
    "serial": "serial",
    "options": "options",
    "search": "search"
  }
}
*/

Step C: The Instructions in Action

During compilation, three primary instructions are executed sequentially:

1. buildColgroup

Queries $.columns and creates a <col> tag for each entry, injecting it into [data-role="table-colgroup"]:

// Blueprint from spec.buildColGroup:
{
  "tagName": "col",
  "attributes": { "style": "width: ${width};" }
}

2. buildHeader

Queries $.columns and generates <th> tags into [data-role="table-header-row"]:

// Blueprint from spec.buildHeader:
{
  "tagName": "th",
  "textContent": "${columnName}",
  "attributes": {
    "class": "py-3 px-3 fw-semibold text-uppercase small text-body-secondary border-bottom"
  }
}

3. buildBody (2D Matrix Execution)

The instruction type is rowOnColumn. For every object in $.data, it instantiates a buildBodyTr, and for each column, it injects a buildBodyCell:

// Body Row:
{ "tagName": "tr", "attributes": { "class": "align-middle" } }

// Body Cell:
{
  "tagName": "td",
  "textContent": "${rowValue}",
  "attributes": { "class": "py-2 px-3 text-secondary" }
}

3. Pluggable Table Options (Decorators)

Every table definition supports optional feature plugins that mutate the table structure cleanly:

A. Serial Number Column (serial)

Automatically prepends sequence numbers (1, 2, 3...) to the table:

  • Unshifts colGroupForSerial (width: 50px) into <colgroup>.
  • Unshifts headerSerialCell (<th>#</th>) into the header row.
  • Unshifts an incrementing index cell into each body row.
  • Unshifts an empty spacing cell into the footer row.

B. Action Buttons Column (options)

Appends row-level action buttons:

  • Appends colGroupForOption (width: 100px) into <colgroup>.
  • Appends headerForOption (<th>Options</th>) into the header row.
  • Appends optionsButtonCell (a button with ks-btn-show) into each body row.
  • Appends tdWithButtonSaveWarning (a button with ks-btn-save) into the footer row.

C. Search Bar (search)

Prepends an interactive search input bar (tableSearch) above the table in the parent container.

4. Complete Compiler Demonstration

Here is an illustration of how a compiler consumes the specifications to generate HTML:

import { spec, definitions, instructions } from "spec-repo";

function buildTable({ inColumns, inRows, inWithFooter = false }) {
  const localRecipe = inWithFooter ? definitions.table.withFooter : definitions.table.simple;
  
  // 1. Clone the base table skeleton from spec
  const tableAst = JSON.parse(JSON.stringify(spec[localRecipe.baseFromSpec]));

  // 2. Colgroup: Populate <col> tags
  const colgroupNode = tableAst.children.find(n => n.attributes?.['data-role'] === 'table-colgroup');
  inColumns.forEach(col => {
    colgroupNode.children.push({
      tagName: "col",
      attributes: { style: `width: ${col.width || 'auto'};` }
    });
  });

  // 3. Header: Populate <th> tags
  const theadRow = tableAst.children.find(n => n.tagName === 'thead').children[0];
  inColumns.forEach(col => {
    theadRow.children.push({
      tagName: "th",
      textContent: col.columnName,
      attributes: { class: "py-3 px-3 fw-semibold text-uppercase small" }
    });
  });

  // 4. Body: Populate rows & cells
  const tbodyNode = tableAst.children.find(n => n.tagName === 'tbody');
  inRows.forEach(row => {
    const tr = { tagName: "tr", attributes: { class: "align-middle" }, children: [] };
    inColumns.forEach(col => {
      tr.children.push({
        tagName: "td",
        textContent: String(row[col.columnName] ?? ""),
        attributes: { class: "py-2 px-3 text-secondary" }
      });
    });
    tbodyNode.children.push(tr);
  });

  return tableAst;
}
