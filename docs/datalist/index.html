How to Build Datalists

Harness the native browser autocomplete engine with zero runtime overhead using declarative <datalist> specifications.

1. Why Datalists?

Traditional searchable dropdowns often bundle hundreds of kilobytes of third-party JavaScript (such as Select2, Chosen, or React-Select). The HTML5 <datalist> element delivers instantaneous, accessible search and auto-complete right inside the browser engine natively.

spec-repo pairs table footers, search bars, and form inputs directly with declarative datalist providers.

2. The Datalist Specifications

Two templates define the datalist ecosystem:

1. Container (buildDataList)
Defines <datalist id="${columnName}">. The id attribute acts as the lookup bridge for inputs.
2. Option Items (buildOption)
Defines <option value="${rowValue}"> nested inside the datalist container.

Raw Template Blueprints

// 1. spec.buildDataList
{
  "tagName": "datalist",
  "attributes": {
    "id": "${columnName}"
  },
  "children": []
}

// 2. spec.buildOption
{
  "tagName": "option",
  "textContent": "${rowValue}",
  "attributes": {
    "value": "${rowValue}"
  }
}

3. Connecting Inputs to Datalists

Notice how spec.buildFooter in the table specification seamlessly couples with buildDataList: 

// spec.buildFooter
{
  "tagName": "td",
  "attributes": { "class": "p-1" },
  "children": [
    {
      "tagName": "input",
      "attributes": {
        "class": "form-control form-control-sm",
        "placeholder": "${columnName}",
        "list": "${columnName}" // <-- References the datalist id!
      }
    }
  ]
}

When an input has list="City", the browser automatically connects it to <datalist id="City">, offering user filtering, arrow-key navigation, and instant selection out of the box.

4. Assembly Instruction (buildDataListWithOptions)

In src/v17/instructions.json, datalists are compiled via the columnOnRow directive:

{
  "buildDataListWithOptions": {
    "type": "columnOnRow",
    "narration": "Build datalists with options",
    "destinationPath": {
      "fileName": "base",
      "filePath": ["children"]
    },
    "templateKey": {
      "columnKey": "buildDataList",
      "rowKey": "buildOption"
    }
  }
}

5. Complete Code Example

import { spec } from "spec-repo";

function buildColumnDatalist({ inColumnName, inSuggestions }) {
  // 1. Clone the datalist container
  const datalistAst = {
    tagName: "datalist",
    attributes: {
      id: inColumnName
    },
    children: []
  };

  // 2. Populate distinct suggestion options
  const uniqueItems = Array.from(new Set(inSuggestions));
  uniqueItems.forEach(item => {
    datalistAst.children.push({
      tagName: "option",
      textContent: item,
      attributes: {
        value: item
      }
    });
  });

  return datalistAst;
}

// Usage:
const cityDatalist = buildColumnDatalist({
  inColumnName: "City",
  inSuggestions: ["New York", "London", "Tokyo", "Paris", "Berlin"]
});

console.log(cityDatalist);

Resulting Output

<!-- Linked Input -->
<input type="text" class="form-control" placeholder="Search City..." list="City">

<!-- Native Datalist Provider -->
<datalist id="City">
  <option value="New York">New York</option>
  <option value="London">London</option>
  <option value="Tokyo">Tokyo</option>
  <option value="Paris">Paris</option>
  <option value="Berlin">Berlin</option>
</datalist>
